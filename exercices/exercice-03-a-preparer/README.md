# Exercice 3 - Espace de travail

Ce dossier est volontairement laisse vide pour preparer le 3e et dernier exercice dans le meme depot.

## Objectif

Conserver une structure propre et homogene :

- un dossier par exercice
- un README par exercice
- les fichiers de configuration ranges avec leur sujet

## Proposition d'organisation

Quand l'exercice 3 commencera, il suffira d'ajouter ici :

- le `README.md` de suivi
- les fichiers de configuration
- les scripts ou captures necessaires

Ainsi, le depot restera coherent pour la relecture et l'evaluation finale.
